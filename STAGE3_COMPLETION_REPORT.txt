1.1 Database Models & Helper Functions (db.py):
  - ImageJob Model:
    * id: String(64) primary key with default generator (imgjob-<12-hex>).
    * project_id: Foreign key to projects.id (CASCADE delete), indexed.
    * user_id: Foreign key to users.id, indexed.
    * workflow_id: String(100) referencing registered ComfyUI workflow.
    * status: String(30), indexed (queued, running, completed, failed, cancelled).
    * comfy_prompt_id: String(100) tracking ComfyUI prompt ID.
    * input_params: JSON storing generation parameters.
    * progress: Integer (0-100%).
    * current_step / total_steps: Integer tracking live step progress.
    * error_message: Text storing error / timeout / OOM diagnostics.
    * created_at / updated_at / completed_at: DateTime timestamps.
    * outputs: Cascading relationship to ImageOutput.
  - ImageOutput Model:
    * id: String(64) primary key with default generator (out-<12-hex>).
    * job_id: Foreign key to image_jobs.id (CASCADE delete), indexed.
    * filename, file_path, thumbnail_path, width, height, seed.
    * output_metadata: JSON sidecar payload.
  - Project Purge Integration:
    * Extended _purge_project_row() to automatically remove related ImageOutput
      records before ImageJob records during permanent project purges.
  - Database Helper API:
    * create_image_job(), update_image_job(), get_image_job(), list_image_jobs(),
      add_image_output(), get_image_output().

1.3 Project-Contained Image Storage (services/image_engine/image_storage.py):
  - Strict Project Containment:
    * Uses services.ingestion.contained_upload_path to ensure all files reside under
      <data_dir>/projects/<project>/generated_images/<job_id>/.
    * Enforces path containment; raises StorageSecurityError on traversal attempts.
  - Filename Sanitization:
    * Strips path separators and unsafe shell characters.
  - Atomic Writes:
    * Writes images and metadata sidecars via temporary files before atomic replace.
  - Thumbnail Generation:
    * Generates 256x256 antialiased thumbnails using Pillow (LANCZOS).
  - Metadata Sidecar:
    * Saves companion .meta.json file alongside every generated image.
  - Cross-Project Access Enforcement:
    * get_output_paths() verifies requesting project matches job's owning project.

1.4 Job Service & FIFO Execution Scheduler (services/image_engine/job_service.py):
  - Single-Worker FIFO Queue:
    * Uses asyncio.Queue with single worker task (concurrency = 1).
    * Strictly preserves the 16 GB VRAM envelope on RTX 5080 while Ollama is running.
  - Crash Recovery:
    * _reconcile_interrupted_jobs() resets stale in-flight jobs to failed on startup.
  - Execution Tracking:
    * Preflight ComfyUI reachability check.
    * Graph compilation via workflow_registry.
    * Input image upload support for sketch-to-render workflows.
    * Live step and percentage progress streaming into SQLite.
  - Cancellation:
    * Supports cancellation; dispatches interrupt signal to ComfyUI if running.
  - Resource & Error Trapping:
    * Catches ComfyUIOutOfMemoryError and records actionable memory instructions.
    * Handles timeouts and disconnected states without server crashes.
  - Audit Logging:
    * Logs audit events (image.job.create, image.job.complete, image.job.fail, image.job.cancel).
