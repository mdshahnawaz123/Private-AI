In accordance with user authorization for Stage 4, the backend API controller,

1.1 REST API Controller (services/image_engine/api.py):
  - Mounted image_router under /api/image-engine:
    * GET /api/image-engine/status:
      Live health check of ComfyUI, active model, VRAM metrics, queue depth,
      and count of registered workflows. (Requires auth).
    * GET /api/image-engine/workflows:
      List available architectural workflows and parameter definitions. (Requires auth).
    * POST /api/image-engine/jobs:
      Submit generation job via application/json or multipart/form-data with sketch
      upload. Validates dimensions, styles, steps. Enforces require_project.
    * GET /api/image-engine/jobs:
      List recent jobs within an authorized project. Enforces require_project.
    * GET /api/image-engine/jobs/{job_id}:
      Retrieve execution status, percentage progress, step counts, duration, and
      outputs for a specific job. Enforces project access.
    * GET /api/image-engine/jobs/{job_id}/outputs:
      Fetch output records and download URLs for a completed job. Enforces project access.
    * GET /api/image-engine/outputs/{output_id}/file:
      Download full-resolution generated image binary with project containment check.
    * GET /api/image-engine/outputs/{output_id}/thumb:
      Serve 256x256 thumbnail for fast gallery rendering with project containment check.
    * POST /api/image-engine/jobs/{job_id}/cancel:
      Cancel active or queued generation job. Only owner or admin may cancel.

1.2 Production Mounting & Lifecycle Hooks (main.py):
  - Mounted image_router alongside api_v1 in main.py.
  - Attached @app.on_event('startup') handler _start_image_engine_scheduler() to start
    the single-worker FIFO queue on process startup.
  - Attached @app.on_event('shutdown') handler _stop_image_engine_scheduler() for
    graceful worker shutdown.

1.3 Security & Access Control:
  - All endpoints enforce JWT Bearer authentication via auth.py.
  - Project-scoped endpoints enforce auth.require_project(request, project).
  - Cross-project access is strictly rejected with 403 Forbidden.
  - Path traversal attempts in project names or output IDs are blocked.
