3. SECURITY, AUTHENTICATION & OFFLINE INTEGRITY
--------------------------------------------------------------------------------
1. Authentication:
   - Same-origin API requests utilize window.fetch wrapper injecting Authorization: Bearer.
   - Browser <img> tags and <a> download links append ?token=${encodeURIComponent(authToken)},
     authenticated server-side via auth.user_from_request().
2. Path Containment:
   - All image retrieval routes enforce strict project path boundaries via
     ImageStorage.get_output_paths(), raising StorageSecurityError (403) on escape attempts.
3. 100% Offline:
   - Zero remote font downloads, zero CDN imports, zero external analytics or telemetry.
   - All SVG icons are rendered inline.
