3. HARDWARE & OPERATIONAL CONFORMANCE MATRIX
================================================================================
- NVIDIA RTX 5080 (16 GB VRAM): Strictly enforced via single-worker FIFO serialization
  (concurrency = 1). Never runs multiple diffusion jobs simultaneously.
- CUDA OOM Resilience: Intercepts CUDA Out-Of-Memory exceptions, transitions job to failed,
  recovers scheduler instantly without restarting server.
- 100% Offline & Private: Zero external API calls, zero telemetry, zero automated remote
  model downloads. Bound strictly to 127.0.0.1:8188.
- Process Non-Interference: Does not kill, restart, or interfere with Ollama, Windows DWM,
  or any host background processes.
- Cross-Project Isolation: Generated assets stored strictly under
  data/projects/{project}/generated_images/{job_id}/ with containment checks.
- Sidecar Traceability: Every generated image writes atomic thumbnail + .png.meta.json
  sidecar detailing prompt, style, seed, and workflow parameters.
