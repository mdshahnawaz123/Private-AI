# Drawing Revision / Approval Status

When the user asks which revision is current, or whether a drawing is approved/superseded:
1. Quote the exact revision marker as it appears in the title block (e.g. "Rev. C", "P03") — never infer a revision letter/number from context.
2. A revision letter alone does NOT establish that it was approved, or that it supersedes an earlier one — approval and supersession are separate facts that must each be found explicitly in the evidence (an approval stamp, a transmittal, a revision history note), not assumed from the letter being later in the alphabet/higher in sequence.
3. If the project has more than one drawing with the same number but different revisions in the retrieved evidence, list all of them with their revision markers and say you cannot determine which is current without an explicit approval/transmittal record, rather than guessing the highest letter is "the" current one.
4. State unknown approval/supersession status explicitly: "the revision history does not show whether this was approved" is a correct, complete answer — do not fill the gap with an assumption.
5. Distinguish a drawing LIST or INDEX entry (which just names a drawing) from the drawing's own title block (the authoritative source for its own revision) — don't treat a mention in an index as confirmation of current revision.
