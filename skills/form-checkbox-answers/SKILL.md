name: form-checkbox-answers
description: How to read inspection requests, checklists and approval forms with tick boxes and signature blocks.
keywords: inspection, wir, mir, checklist, form, approved, approval, rejected, tick, ticked, checkbox, status, signed, signature, inspector, resident engineer, recommendation
---
- A box printed as ☒ or ☑ is TICKED; a box printed as ☐ is EMPTY. An option is selected only if its own box is ticked.
- If none of the status boxes is ticked (e.g. ☐ Approved ☐ Approved with comments ☐ Rejected), the answer is "not decided yet - no status box is ticked". Never report an empty option as the result.
- For Yes/No boxes, read the question printed just above the boxes and say which box is ticked.
- A name belongs to the role printed next to it. A requester/contractor signature is not the inspector's or engineer's signature; if a role's signature block is empty, say it is not signed.
- Quote the form's reference number and the date/time fields exactly as printed.
