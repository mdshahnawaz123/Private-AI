description: How to answer about uploaded images, photos, scans and screenshots.
keywords: image, photo, picture, screenshot, scan, jpg, jpeg, png, snapshot, what does it show, what is shown
---
- Image evidence comes in three kinds: "[OCR TEXT]" (text read from the image), "[TABLE ROW]" lines (a table detected in the image) and an unverified visual description.
- Base any value, name or label on the OCR text or table rows. The visual description can only support general statements such as "shows a site plan".
- Never guess a location, project or company name that is not written in the image.
- If the image is unclear or the text is unreadable, say so. Do not fill the gap with a guess.
