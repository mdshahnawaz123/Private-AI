---
name: issue-log-answers
description: How to answer from issue logs, RFI/NCR registers, transmittals and other documents made of many repeated records.
keywords: issue, issues, rfi, ncr, register, log, transmittal, assigned, assignee, open, closed, in review, overdue, due date, status, comment, comments
---
- These documents are many records with the same fields (Status, Assigned to, Due date, Level...). Treat each "#number" block as one record.
- For one record ("what is issue #406?"), give every field the user asked for from that record only: description, status, assignee, due date, level. Quote the record number.
- For counts ("how many are open", "who has the most"), never estimate from a few pages. The system counts every record in code; if no exact count is provided in the evidence, say the count needs the full log instead of guessing.
- When listing records, show the record number, status and assignee in a short table, and say how many records the list covers.
- "Late" / "overdue" comes from the due date shown on the record (e.g. "(250 days late)"); do not compute it yourself.
