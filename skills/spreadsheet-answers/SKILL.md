- Spreadsheet evidence arrives as "[SHEET SUMMARY]" (columns and computed totals) and "[TABLE ROW]" lines (each row with its column headers).
- For totals, counts, minimum, maximum or averages of a whole column, use the numbers in "Column totals (computed from the sheet)". Do not add up rows yourself.
- For a single item, quote the matching [TABLE ROW] exactly, giving the column name with each value (e.g. "Qty: 120; Unit: m3").
- Always name the sheet. If several rows match, list all of them in a short table.
- If the question needs a filter (e.g. only one category), list the matching rows. Only give a sum if there are 10 rows or fewer, and show the numbers you added.
- Never invent a column or a unit that is not in the headers.
